LSpectrum 4.5dB Analyzer — Full Quick Guide

Snapshot 0.24 — Updated after the new accessible selection workflow

What LSpectrum is

LSpectrum 4.5dB Analyzer is an accessible spectrum analysis system for REAPER made of two parts:

  • a JSFX analyzer, which measures the spectrum in real time
  • a Lua interface, which turns the result into a spoken, navigable table for screen-reader users

The system is designed to analyze the relationship between frequency bands, not the absolute playback loudness.
What matters is the tonal shape of the spectrum: lows, mids, highs, and their balance against a chosen target curve.

The analyzer works very well for blind and visually impaired users because the result is not just “shown”: it is made explorable, repeatable, copyable, and comparable by keyboard and speech.

General concept

The analyzer divides the signal into 32 logarithmic bands from about 22 Hz to 18 kHz.
For each band, it calculates the difference in dB between the measured audio and a chosen target curve.

So the reported value is not simply “how loud that band is”, but:

  • negative = that band is below the target curve
  • positive = that band is above the target curve
  • 0 dB = that band is aligned with the target curve

This makes LSpectrum especially useful for:

  • tonal balance checking
  • comparing material against a musical slope
  • low-end and high-end inspection
  • focused analysis of only selected bands
  • accessible reading of spectral shape without relying on graphics

JSFX overview

Plugin name: JS: LSpectrum 4.5dB Analyzer

Main functions

The JSFX:

  • performs the actual FFT analysis
  • uses a 32768-point FFT
  • divides the spectrum into 32 logarithmic bands
  • writes one dB difference value to each of 32 sliders
  • can generate a reference stereo noise
  • can generate a tone for audible band checking
  • passes audio through without coloration unless the noise or tone are enabled

Frequency bands

The 32 bands are centered approximately at:

22.3, 27.6, 34.3, 42.6, 52.8, 65.6, 81.4, 101,
125, 155, 193, 239, 297, 369, 458, 568,
705, 874, 1085, 1346, 1671, 2073, 2573, 3193,
3962, 4916, 6101, 7571, 9395, 11659, 14468, 17954 Hz

Target curves

The JSFX supports these target curves:

  • Flat 0 dB
  • Pop Soft 2 dB
  • Old Pop / Rock 3 dB
  • Modern Pop 4 dB
  • EDM / Synth Pop 4.5 dB
  • Trap / Urban 5 dB
  • Lo-Fi Warm 6 dB

These are not EQ presets. They are reference spectral slopes used to compare the measured signal against a musical tonal profile.

Noise reference

The JSFX includes a stereo reference noise output controlled by slider33.

It blends:

  • pink-like noise
  • brown-like noise

This can help as a listening reference while analyzing tonal balance.

Tone generator

The JSFX also includes a sine tone generator:

  • On/Off
  • frequency in Hz
  • level in dB

The Lua script uses this as an audible aid to inspect the current band.

Silence handling

If the input is effectively silent, the JSFX sets the band sliders to a very low value so the Lua script can detect that no meaningful signal was present.

Lua script overview

Script name: LSpectrum Analyzer – 10s Analysis + Accessible 3-Column Table

The Lua script is the accessible front end. It:

  • loads the JSFX automatically
  • ensures analysis can be run on master or selected track
  • asks for analysis duration
  • speaks the countdown
  • builds the result table
  • lets you move through rows and columns
  • lets you copy lines or full results
  • lets you select only specific bands for the next scan
  • stores the last genre and duration
  • opens the TXT report when needed

The result TXT file is stored here:

/REAPER/Scripts/Lo-lo - Scripts/analysis/LSpectrum 4.5dB Analyzer/spectrum_LastResult.txt

If you have old snapshots, remove any outdated result file from previous locations to avoid confusion.

Important behavior

The analysis is relative, not absolute

LSpectrum is built around spectral balance.
If the whole signal becomes louder or quieter uniformly, the important result does not really change: the shape remains the same.

That means the analyzer is best understood as a tonal balance tool, not as a loudness meter.

The JSFX is controlled from Lua

You normally do not need to open the JSFX directly.
The Lua interface manages:

  • analysis start
  • track target
  • result table
  • curve selection
  • tone preview
  • noise reference
  • selection of active bands
  • copying and exporting

The analyzer should stay at the end of the FX chain

The analyzer is intended to read the final signal after all processing, so it should be loaded at the end of the FX chain, not at the top.

Main menu

When the script starts, it offers:

  1. New Analysis
  2. Last Analysis
  3. Kick Analysis (Bands 1–14)
  4. New Analysis on Selected Track

Menu entries explained

New Analysis
Starts a normal full-spectrum analysis.

Last Analysis
Loads the last saved result and opens the accessible result table.

Kick Analysis (Bands 1–14)
Starts an analysis limited to the lower portion of the spectrum. Useful for kick, bass, sub, and low-mid inspection.

New Analysis on Selected Track
Runs the analysis on the currently selected track instead of master.

Countdown phase

Before analysis starts, the script asks for the duration in seconds.

  • Minimum supported duration: 10 seconds
  • The chosen duration is remembered in ExtState
  • During countdown, spoken numbers announce the remaining time
  • You can interrupt the countdown with Escape

Countdown controls

  • Space: Play/Stop REAPER
  • Esc: cancel the countdown and close

Result table structure

The result table has 3 columns:

  1. Band number
  2. Frequency
  3. Difference in dB

Example line:

Band 19 | 1085 Hz | +0.00 dB

This means that the measured level of band 19 matches the selected target curve at that frequency.

Result table navigation

Row and column movement

  • Up Arrow: previous row
  • Down Arrow: next row
  • Left Arrow: previous column
  • Right Arrow: next column
  • Home: first row
  • End: last row
  • Page Up: move up 8 rows
  • Page Down: move down 8 rows

Reading commands

  • Tab: speak current cell
  • Double Tab: speak full current line
  • Triple Tab: copy full current line to clipboard

Direct read / copy commands

  • 1: speak current band number
    • press twice quickly: copy band number
  • 2: speak current frequency
    • press twice quickly: copy frequency
  • 3: speak current dB value
    • press twice quickly: copy the dB value

Full copy

  • Ctrl+C: copy the whole current report to clipboard

The copied report includes the result title and header, not only the table.

Result title and report content

The result title includes:

  • analysis target
  • selected track or master
  • current genre / target curve

Example:

Analysis Result – Master – Default: EDM Synth Pop 4.5 dB

The full copied report includes:

  • result title
  • analysis header
  • table contents

This makes it easy to paste results into notes, emails, documents, or chats without opening the TXT file.

Analysis control keys

  • F1: open the quick guide
  • R: start a new analysis using the stored duration
  • T: switch analysis target to selected track
  • M: switch analysis target to master
  • Space: Play/Stop REAPER
  • Esc: close everything
  • O: open the TXT report and exit

O opens the TXT report file and exits the script.

Target curve control

These keys choose the target curve:

  • A: Flat 0 dB
  • S: Pop Soft 2 dB
  • D: Old Pop Rock 3 dB
  • F: Modern Pop 4 dB
  • G: Default: EDM Synth Pop 4.5 dB
  • H: Trap / Urban 5 dB
  • J: Lo-Fi Warm 6 dB

When you change the curve, the next scan will compare the measured spectrum against that new target slope.

Announcing the next scan settings

  • \: announces how the next scan will be configured

This spoken message includes:

  • current target: track or master
  • current genre / curve
  • number of active bands for the next scan

This is useful before pressing R, because it tells you what the next analysis will use without having to remember the current setup.

Example idea of the message:

Next scan. Master. Default EDM Synth Pop 4.5 dB. 32 bands active.

Tone preview

  • Enter: toggle the sine tone preview on/off

When enabled, the tone uses:

  • the frequency of the current band
  • a level derived from the current dB reading

This can help you “hear” where you are in the table and relate a band to an audible reference.

Noise reference control

  • +: increase reference noise level
  • -: decrease reference noise level

This changes the JSFX noise reference level in dB.

Useful when you want a spectral listening anchor while working.

Band selection mode

One of the major new features is the ability to choose which bands will be included in the next scan.

Entering and leaving selection mode

  • B: toggle Band Selection Mode on/off

When selection mode is active:

  • navigation moves through the full available band range
  • Space no longer controls Play/Stop
  • Space selects or unselects the current band
  • the spoken cell tells you whether the band is selected or unselected

When selection mode is off:

  • the result table shows only the currently active bands
  • Space returns to normal Play/Stop behavior

Band selection mode behavior

Inside selection mode:

  • Up/Down/Home/End/Page Up/Page Down navigate bands
  • Space toggles selection of the current band
  • 1 speaks the band number
  • 2 speaks the frequency
  • 3 speaks selected/unselected state
  • Tab still reads the current cell or line
  • R is still active for immediate restart
  • other normal keys remain usable

Selection logic

If no bands are explicitly selected, the next scan uses all available bands.

So:

  • in normal full analysis, no selection means 32 bands active
  • in kick mode, no selection means 14 bands active

Restore all bands

  • Delete: restore all bands at once

This works both:

  • inside Band Selection Mode
  • outside Band Selection Mode

That means you can instantly return to the full active set without first pressing B.

The spoken message confirms that all bands are restored and reports how many are active.

Examples:

  • All bands restored. 32 bands active.
  • All bands restored. 14 bands active.

This is especially useful before pressing R, because it instantly resets the next scan to the full available set.

Kick analysis behavior

Kick Analysis uses only the lower range:

  • Bands 1–14

This is useful for:

  • kick fundamental
  • sub and low bass
  • body / punch region
  • low-mid balance

All the selection features still work there, but the selectable range is limited to 14 bands.

So in kick mode:

  • selection mode only navigates bands 1–14
  • Delete restores all 14 active kick bands
  • the next scan announcement reports 14 active bands if nothing is selected manually

Loading the last analysis

When you choose Last Analysis, the script loads the previously saved TXT result and rebuilds the table.

The loaded result keeps:

  • band table
  • band order
  • current stored genre label
  • accessible navigation
  • full copy support

This is useful when you want to reopen a result without rerunning the scan.

Typical workflow

Standard full-spectrum workflow

  1. Launch the script.
  2. Choose New Analysis or New Analysis on Selected Track.
  3. Enter the analysis duration.
  4. Let the countdown run while audio plays.
  5. After the scan, navigate the table with arrows.
  6. Use Tab, 1, 2, 3 to inspect the result.
  7. Use A/S/D/F/G/H/J to choose a different target curve.
  8. Press \ to hear how the next scan is currently configured.
  9. Press R to rerun the analysis with the stored duration.
  10. Press Ctrl+C if you want the whole result on the clipboard.

Focused workflow with selected bands

  1. Run an analysis.
  2. Press B to enter Band Selection Mode.
  3. Move with arrows to the bands you care about.
  4. Press Space to select or unselect them.
  5. Press Delete at any time if you want to restore all bands.
  6. Press B again to leave selection mode.
  7. Press \ to confirm how many bands the next scan will use.
  8. Press R to run a new analysis on only those bands.

Quick restore workflow

If the visible table currently shows fewer bands and you want all of them back immediately:

  1. Press Delete
  2. All bands are restored
  3. Press R to run the next scan with the full band set

No need to enter Band Selection Mode first.

Why this analyzer is useful

LSpectrum is especially useful because it does not try to replace hearing.
It supports hearing with structured, repeatable information.

It is good for:

  • tonal balance inspection
  • comparing mixes against a chosen slope
  • checking low-end distribution
  • learning spectral relationships
  • making spectrum analysis usable without sight

For blind users, this is particularly valuable because many analyzers on the market are visually rich but conceptually poor in accessibility. LSpectrum instead turns the spectrum into a spoken table that can actually be navigated and understood.

Practical interpretation tips

  • A result around 0 dB means the band matches the target curve
  • Large negative values mean that band is weaker than the target
  • Large positive values mean that band is stronger than the target
  • What matters most is the shape across bands, not the absolute loudness of the file
  • A louder or quieter file with the same tonal shape will produce essentially the same useful reading

So LSpectrum is best treated as a spectral relation analyzer, not a simple level meter.
